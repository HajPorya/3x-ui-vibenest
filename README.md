# 🇬🇧 English

## About

This repository is a **VibeNest-ready Sanaei 3X-UI project**.

To use it, simply **Fork this repository** to your GitHub account and deploy your fork on VibeNest.

## ⭐ How to Use

### 1. Fork

Click the **Fork** button at the top of this repository and create your own copy.

### 2. Deploy on VibeNest

Select your forked repository in VibeNest and deploy it.

The project already contains the required deployment files and is prepared for running Sanaei 3X-UI.

### 3. Access the Panel

After deployment is completed, open the URL provided by VibeNest to access the 3X-UI panel.
