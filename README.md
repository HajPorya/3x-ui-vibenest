# 3X-UI — GitHub upload wrapper

This repository is a convenient way to upload the 3X-UI source to GitHub from a phone.
It contains:
- `Dockerfile`
- `3x-ui-source.zip`

After uploading, VibeNest should be configured according to its Docker build/runtime
requirements. The included Dockerfile is an upload wrapper and is NOT a replacement
for the upstream 3X-UI runtime configuration.
